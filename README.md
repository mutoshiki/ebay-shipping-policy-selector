# Film Camera Shipping Guide V8

## 更新内容
- eBay送料V3（100g〜1000g、100g刻み）へ更新
- 米国・英国・ドイツ・オーストラリアをSpeedPAK Economyで個別表示
- 中国・韓国・台湾、カナダ・欧州など主要な配送先を結果画面に常時表示
- その他の地域は日本郵便 国際エアパケットの地帯別料金
- 梱包方法・梱包材重量・付属品を折りたたまず常時表示
- 商品価格を任意入力へ変更（V3の送料判定は重量のみ）
- Codexへ送った設定プロンプトをツール画面から確認・コピー可能
- 履歴には配送ポリシー、送料テーブル、主要4か国の送料を保存
