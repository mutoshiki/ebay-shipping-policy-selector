# Film Camera Shipping Assistant

eBay向けの梱包重量・配送Policy判定ツールです。

- 2026-09-21時点の米国DDP Policyを「商品価格帯 × 請求判定重量」で判定
- 保存済み8Policyと未作成候補1件を区別
- 実重量以上をカバーする最小のPolicy重量枠へ切り上げ
- Policy重量枠と同じ `INT-AP-SPK-xxxxG-V3` Rate Tableを使用
- 箱サイズを入力した場合は、実重量と容積重量（縦×横×高さ÷8000kg）の大きい方で判定
- 箱サイズ未入力時は実重量のみで暫定判定
- 梱包材・付属品重量の自動見積もり、実測値、履歴保存に対応

例：440g / $34.99 → `CAM-US-0-49-600G`

`CAM-US-50-99-600G` は未作成候補で、参考送料 $39.18 は確定値として扱いません。
